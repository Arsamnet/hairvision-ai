# 01 - Product Scope MVP

## تعریف محصول

HairVision یک lead generation + visual simulation service برای کلینیک‌های کاشت مو است.

کاربر نهایی از طریق آدرس اختصاصی مشتری وارد می‌شود، شماره موبایل خود را تایید می‌کند، عکس آپلود می‌کند و خروجی شبیه‌سازی را دریافت می‌کند. مدیر کلینیک در داشبورد، لیدها، عکس‌ها، وضعیت پردازش و خروجی‌ها را می‌بیند.

## اهداف MVP

- جذب لید برای هر مشتری/کلینیک
- ذخیره شماره موبایل تاییدشده
- دریافت عکس کاربر
- اجرای جریان پردازش تصویر به‌صورت queue-based
- نمایش خروجی 3 ماه، 6 ماه و 12 ماه
- استفاده از provider تستی تا زمان اتصال به AI واقعی
- داشبورد ساده مدیر مشتری
- آماده‌سازی معماری برای Next.js در آینده

## موارد داخل MVP

### Public Visitor Flow

1. ورود به آدرس tenant
2. مشاهده landing page
3. وارد کردن شماره موبایل
4. دریافت OTP
5. تایید OTP
6. آپلود عکس
7. ثبت job پردازش
8. مشاهده وضعیت پردازش
9. مشاهده نتایج

### Admin Flow

1. ورود مدیر tenant
2. مشاهده dashboard
3. مشاهده لیست leads
4. مشاهده جزئیات lead
5. مشاهده uploads و generated assets
6. خروجی CSV ساده
7. تنظیمات پایه theme
8. تنظیم provider پیش‌فرض tenant

### Platform Admin Flow

1. مدیریت tenants
2. مدیریت tenant domains
3. مدیریت AI providers
4. مشاهده jobهای failed
5. مشاهده مصرف tenantها
6. فعال/غیرفعال کردن tenant

## موارد خارج از MVP

- Next.js frontend واقعی
- CRM کامل
- پرداخت آنلاین
- فرم‌ساز پیشرفته
- قالب‌ساز drag & drop
- Cloudflare for SaaS خودکار
- مدل AI اختصاصی
- آموزش مدل AI
- اتصال مستقیم به WordPress مشتری
- ویرایشگر عکس سمت کاربر
- live progress با WebSocket

## معیارهای موفقیت MVP

- ثبت موفق lead با OTP
- آپلود موفق عکس با validation
- اجرای job بدون دخالت کاربر
- نمایش 3 خروجی نمونه با SampleImageProvider
- داشبورد قابل استفاده برای مدیر
- عدم نشت اطلاعات بین tenantها
- آماده بودن API برای استفاده توسط Next.js در آینده
